# Unity DevTools

A collection of lightweight editor utilities for Unity.

## Features

* **Open in IDE:** Adds an `Assets > Open in VS Code` context menu item to open UI Toolkit assets (`.uxml`, `.uss`) directly in your configured external code editor instead of UI Builder.

## Installation

### Via Git URL
In Unity: **Window > Package Manager** > click **`+`** > **Add package from git URL...**
```text
[https://github.com/yeahrik/com.yeahrik.unity.devtools.git](https://github.com/yeahrik/com.yeahrik.unity.devtools.git)
```

### Via `manifest.json`
Add to `Packages/manifest.json` under `dependencies`:
```json
"com.yeahrik.unity.devtools": "[https://github.com/yeahrik/com.yeahrik.unity.devtools.git](https://github.com/yeahrik/com.yeahrik.unity.devtools.git)"
```
